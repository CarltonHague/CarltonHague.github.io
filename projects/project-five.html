PlayStation 4 Game

A C++ game for PlayStation 4, improved over 12 weeks as part of a hardware and software optimisation module. The project focused on making an existing game codebase more efficient through SIMD and data-oriented design.

Role
Codebase cleanup and performance optimisation
Tools
C++, Intel intrinsics
Platform
PlayStation 4
Timeframe
12 weeks

About the project

Completed as part of a hardware and software optimisation module, this project involved working with a supplied game codebase and improving its poorly optimised systems. Rather than starting from scratch, we had to understand, clean up, and optimise existing code while preserving the game’s behaviour. This gave me experience managing and working effectively within an established codebase.

What I worked on

  • I used SIMD with Intel intrinsic registers to optimise update operations and matrix multiplication.
  • I reworked the game’s object handling into a data-oriented design (DOD), storing objects in memory-aligned arrays managed by a single class.
  • This layout improved data locality during the main game loop, helping cache hits and reducing cache misses.
  • I cleaned up and optimised the supplied code, developing my ability to understand, manage, and make changes within an existing codebase.
