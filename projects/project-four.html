About the project

This project was created as a solo university project and focused on building an asteroids-style game in SFML. The goal was to create a playable arcade shooter with smooth but intentionally challenging movement, a layered mountain backdrop, and a modular code structure that could support expanding gameplay.

What I worked on

  • I implemented the ship movement and turning behaviour using a lerp-style approach so the rotation and acceleration felt weighted and less responsive, creating a more difficult flight feel.
  • I built the game using object-oriented C++ structure, keeping the code modular and easier to maintain as the project expanded.
  • I used object pooling for both bullets and enemy objects to improve performance and make the gameplay feel smoother during heavier action.
  • I created the parallaxing mountain background system to make the ship feel as though it was flying through a layered landscape while maintaining the arcade action.
