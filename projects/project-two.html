About the project

This project was a short game development challenge where we built a Flappy Bird-inspired game in C++ using SFML. The goal was to create a polished, playable prototype within a tight timeline while balancing fun mechanics, performance, and presentation.

What I worked on

  • I helped build the core gameplay systems, including movement, collision detection, and score progression.
  • I worked on tuning the game feel so the controls felt responsive and the difficulty curve remained engaging.
  • I contributed to the overall project structure and iteration process, helping the team refine the prototype over the 4-week development cycle.
